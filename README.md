# EpicWakerUpper
EpicWakerUpper is an alarm clock powered by a Seeed XIAO ESP32C3. Additionally, this alarm clock features 6 key switches to make selections on its 2.25-inch TFT screen.


## Features:
+ 6 key switches to navigate throughout the clock system
+ Displays weather, can set an alarm, and can set a timer
+ Wakes you up through sound produced by the buzzer
+ 3D Printed case to make it look good!

## Materials/BOM

+ 1x Seeed XIAO ESP32C3
+ 1x 3.3V Piezo Buzzer
+ 6x MX-Style Keyboard Switches
+ 6x White Blank DSA Keycaps
+ 6x Through-Hole 1N4148 Diodes
+ 1x 2.25in TFT Screen
+ 1x 3.3V Piezo Buzzer
+ 1x 2.54mm 8 Pin Male Header
+ 8x 20cm Female-Female Jumper Wires
